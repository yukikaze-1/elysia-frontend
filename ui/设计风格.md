## 1. 产品视觉定位

Cyrene 的界面不应呈现传统 AI 工具、后台管理系统或开发者控制台的感觉。

核心视觉关键词：

**温柔 / 陪伴 / 清透 / 梦幻 / 克制 / 轻盈 / 安全感 / 精致**

整体目标是：

> 像一个安静、温暖、长期陪伴用户的私人空间，而不是一个堆满功能的 AI 控制面板。

视觉风格以：

**樱花 + 天空 + 玻璃拟态 + 淡紫蓝 + 少量粉色**

为主要语言。

功能界面即使包含模型、API、日志、权限等技术内容，也必须继续保持 Cyrene 的视觉体系，避免突然变成传统灰白后台。

# 2. 核心设计原则

### 2.1 内容优先，装饰退后

樱花、花瓣、渐变和背景插画是氛围元素，不能影响：

- 文字阅读
- 表单填写
- 按钮识别
- 状态判断
- 长时间使用

内容区域必须有足够纯净的玻璃白底承载。

---

### 2.2 多用“层”，少用“框”

不要给每个元素都加粗边框。

推荐通过：

```text
背景
↓
玻璃主容器
↓
内容区域
↓
弱玻璃卡片
↓
按钮 / 输入框
```

形成空间层级。

边框仅用于辅助区分。

---

### 2.3 陪伴感高于科技感

可以出现：

- 柔和渐变
- 爱心
- 花瓣
- 手写文字
- 小型角色插画
- 微弱光晕

尽量避免：

- 纯黑
- 高饱和赛博蓝
- Neon RGB
- 大量粗线条
- 密集数据仪表盘
- 过于工业化的 Material Design 风格

---

### 2.4 功能复杂，但视觉不能复杂

Cyrene 后续可能包含大量：

- LLM
- STT
- TTS
- Live2D
- Memory
- Agent
- Tool
- 权限
- 调试

因此 UI 应通过**层级和留白解决复杂度**，而不是继续增加更多颜色、图标和 Card。

# 3. 色彩系统

## 3.1 主色

| Token | 推荐颜色 | 用途 |
|---|---|---|
| `--color-primary-900` | `#27357F` | 大标题、重点文字 |
| `--color-primary-700` | `#4058C7` | 图标、次重点按钮 |
| `--color-primary-500` | `#687CFF` | 主交互色 |
| `--color-purple-400` | `#A78BFA` | 品牌紫 |
| `--color-pink-300` | `#FFB7D9` | 陪伴、情绪、爱心 |
| `--color-blue-200` | `#BFD8FF` | 辅助蓝 |
| `--color-bg` | `#F8FAFF` | 纯净背景 |

---

## 3.2 品牌渐变

Cyrene 的主渐变建议统一：

```css
background: linear-gradient(
  135deg,
  #7c8cff 0%,
  #a78bfa 52%,
  #f18bd5 100%
);
```

适用于：

- 主按钮
- 当前激活 Tab
- 发送按钮
- 少数重点 CTA

**不要让所有按钮都使用渐变。**

---

## 3.3 页面背景渐变

```css
background:
  linear-gradient(
    135deg,
    rgba(215, 232, 255, 0.92),
    rgba(248, 250, 255, 0.96)
  );
```

可叠加：

- 樱花虚化照片
- 天空
- 阳光
- 花瓣

但需要强 blur / opacity 控制。

## 3.4 情绪色

```text
成功       #36B979
警告       #F6B84B
错误       #EF6A78
信息       #6884F4
陪伴/爱心   #F38FC6
```

状态颜色保持低饱和，不使用传统后台那种刺眼红绿。

# 4. 玻璃拟态规范

Cyrene 的玻璃效果必须是**轻玻璃**，不要做成高反差磨砂玻璃。

### 主窗口 / 大弹窗

```css
background: rgba(248, 250, 255, 0.78);

backdrop-filter:
  blur(22px)
  saturate(115%);

border: 1px solid rgba(255, 255, 255, 0.70);

box-shadow:
  0 18px 60px rgba(55, 72, 138, 0.16);
```

---

### 普通 Card

```css
background: rgba(255, 255, 255, 0.62);

border: 1px solid rgba(170, 188, 235, 0.38);

box-shadow:
  0 6px 20px rgba(55, 72, 138, 0.06);
```

---

### 弱 Card

用于不希望过度强调的区域：

```css
background: rgba(248, 250, 255, 0.45);

border: 1px solid rgba(180, 195, 230, 0.24);
```

核心规则：

> 页面不能全部由高强度 Card 组成。

必须有强、弱、无 Card 三种层级。

# 6. 间距系统

统一采用 **8px Grid System**。

主要数值：

```text
4px   极小微调
8px   图标/文字间距
12px  紧凑组件
16px  标准间距
24px  Card 内间距
32px  模块间距
40px  大模块间隔
48px  页面级留白
```

尽量避免：

```text
13px
19px
27px
31px
```

这种没有体系的间距。

# 25. 背景插画原则

允许：

- 樱花
- 花瓣
- 晨光
- 天空
- 薄云
- 浅粉森林
- 角色局部插画

禁止：

- 大面积高对比人物压在表单后
- 花瓣穿过正文
- 随机强曝光
- 不同页面使用完全不同画风

背景透明度建议：

```text
5–20%
```

Blur：

```text
12–30px
```

# 26. 装饰元素

页面最多存在 **1–2 个主要装饰区域**。

例如：

```text
左下角樱花枝
+
右上角几片花瓣
```

已经足够。

不要：

```text
顶部花瓣
左边花瓣
右边花瓣
Card 花瓣
按钮花瓣
底部樱花
```

全部同时出现。

否则会从“精致”变成“主题皮肤”。

---

# 27. 动画系统

动画原则：

> 温柔、快、轻，不打断用户。

建议：

```text
Hover          120–160ms
Button         150–180ms
Dropdown       160–200ms
Modal          180–240ms
Page transition 200–260ms
```

使用：

```css
cubic-bezier(.2,.8,.2,1)
```

避免：

- Bounce
- 超大 Scale
- 旋转
- 长时间花瓣动画
- 大量粒子

---

# 28. Hover

Card：

```css
transform: translateY(-1px);
```

Button：

```text
brightness +2~4%
shadow slight increase
```

Sidebar item：

```text
非常浅的蓝紫背景
```

同时改变：


```text

```

```text
小月雨正在思考…
正在连接模型…
正在听你说…
```

```text

```

# 31. Empty State

避免冷冰冰：

```text

```

建议根据场景写：

```text

创建一个属于你的陪伴者吧
```

或者：

```text

```

# 32. Error

技术错误：

```text
连接没有成功
可以检查 Endpoint、API Key 或网络设置后再试一次。

查看详情
重新测试
```

不要默认给普通用户展示：

```text

stack trace
```

# 33. 文案风格

Cyrene 的语言应该：

**简洁 + 温柔 + 正常 + 有一点陪伴感**

不能每句话都可爱化。

例如：

✅

> 修改会从下一轮对话开始生效，不会影响历史消息。

比：

❌

> 设置好啦～下一次聊天我就会记住哦 ♥︎

更适合作为设置页面正文。

情感表达应该出现在：

- 会话
- Empty State
- 欢迎页
- 角色互动

# 38. 最重要的 Do / Don't

### Do

- 大量留白
- 强弱分明的视觉层级
- 半透明白色
- 蓝紫为功能主色
- 粉色作为陪伴情绪色
- 背景柔和虚化
- 适量樱花
- 清晰文本对比度
- 少量优质动画
- 简洁组件体系

### Don't

- 每一个区域都 Card
- 每一个按钮都渐变
- 每一个页面都大量花瓣
- 大面积粉色
- 信息文字过浅
- 过度毛玻璃
- 高饱和 Neon
- Button / Input 圆角各不相同
- 随意使用 Emoji 代替图标
- 为了“好看”牺牲可读性

# 39. 一句话设计标准

以后让 AI 修改任何 Cyrene 页面，都可以把这一句放在 Prompt 最后：

# 40. 当前版本视觉基准

目前我们已经定下来的基准可以概括为：

**主界面负责“陪伴感”，设置界面负责“清晰感”，两者通过同样的背景、色彩、玻璃材质、圆角和组件语言连接起来。**

也就是说设置页**不是把主页的樱花效果原封不动搬过去**。

正确关系应该是：

```text
聊天页
情绪表现  ██████████
信息密度  ██████
装饰程度  ████████

设置页
情绪表现  █████
信息密度  █████████
装饰程度  ████
```

这样整个 Cyrene 才会既有鲜明自己的风格，又不会因为“二次元 / 樱花 / 玻璃”而损害实际可用性。
