## 5. allow_scoped 目录授权（批次 C 全链）

| # | 用例 | 操作 | 通过标准 |
|---|---|---|---|
| 5.1 | 授权创建 | read/write 权限窗点「允许指定目录」，选择 Desktop 目录 + TTL | 目录授权创建成功；当前调用按授权执行；`grant:created` 审计 summary **不含目录绝对路径**、含后端身份 origin |
| 5.2 | 授权匹配 | 授权有效期内再 read/write 该目录下文件 | read 无权限窗自动执行；write 无确认窗但卡片显示**只读 Diff**；命中审计 `allow_scoped + permissionGrantId` |
| 5.3 | 段边界 | 请求目录外文件（如用户目录下另一文件夹） | 不匹配授权，恢复权限窗 |
| 5.4 | 黑名单优先 | 授权目录内再尝试访问黑名单命中项（如目录内 `.env` 精确项） | 黑名单 step 5 先拒，永不覆盖授权 |
| 5.5 | 撤销 | 设置 → 安全与权限 → 授权管理点撤销 | 后续同目录 read 恢复权限窗；已撤销项灰显；`grant:revoked` 审计 |
| 5.6 | 审批历史 | 安全与权限 → 审批历史 | 最近桌面工具事件可见；过滤/搜索可用；含授权事件可“撤销此授权”跳转 |
| 5.7 | 身份绑定 | 记录授权后**切换 Endpoint 到另一后端地址**（如 127.0.0.1:8876 假地址），再连回原端点读同目录 | 切换后授权不匹配（fail-safe 弹窗）；连回原端点后恢复匹配（或按失效语义明确） |
