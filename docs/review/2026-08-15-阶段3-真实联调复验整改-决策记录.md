## 3. D1~D4 决策表（复制 spec §5，定案）

| # | 事项 | 定案 | 理由 |
|---|---|---|---|
| D1 | P0-01 绝对签名 URL 策略 | 相对拼接 + 绝对 http(s) scheme 校验放行，**不强同源** | 复验清单 §3.4 要求明确兼容/拒绝策略；对象存储/独立 CDN 可能返回绝对地址，强制同源会误伤；Main 受信边界 fetch 签名 URL（Renderer 只供 attachmentId），scheme 白名单即足够防线 |
| D2 | P0-01 签名缓存失效 | 缓存 key 按 endpoint 身份分区（`${baseUrl}:${attachmentId}`，baseUrl 含反代 path 前缀） | 「origin 分区」落到 baseUrl 粒度：origin 变化必然 baseUrl 变化，且同 origin 不同 path（`/a` 与 `/b` 两部署）也不串签；无需主动清空 |
| D3 | P0-03 贴图恢复范围 | 用户 + assistant 双路径（共享映射）；`STICKER_ID_PATTERN`/src 兜底单一来源 `shared/domain/sticker-url`（content-part 作 main 层门面）；无效 `st_` ID fail-open 忽略 | 领域契约与渲染器两条渲染路径均已冻结；`mapContentToEntries` 是共享入口，双路径近乎零额外成本；贴图为显示增强，无效 ID 不应拒整页；sticker-url.ts 既有已测解析（剥 `.png`+校验），复用避免第三份拷贝与漂移 |
| D4 | §7 后端 MIME | 前端不加兼容层、不扩白名单，等后端 BE-S3-RUN-P0-02；后端修复后补真实契约测试 | 掩盖真值会迟滞后端修复；现有 `wireKindHint`（上传侧消歧）保留，非展示掩盖 |

## 4. 冻结口径（非决策，复验清单已冻结）

- **P0-02 归一化字段集与约束：** 全可空数字（`size_bytes`/`width`/`height`/`duration_ms` + tool 块 `duration_ms`）；判据 `typeof v === 'number' && Number.isFinite(v) && v >= 0`，非法（null/负/NaN/Infinity）→ 字段缺省；`0` 为合法值保留（schema 非负含 0）。单字段缺失不丢媒体、不丢消息页；必填 `attachmentId/kind/mediaType` 仍 fail-closed。IPC/领域 Schema 保持严格（`z.number().nonnegative().optional()` 不变）。
- **P1-01 排序语义：** 领域层统一 `sortKey` 升序；同时间戳用 `hitId`（`timestamp|messageId` 已编码）作稳定次键；cursor 原样使用后端返回值（不参与排序）；排序只作用于展示副本；合并继续按 `hitId` 去重、滚动锚点保持。
- **P0-03 显示语义：** 以冻结的 `Message.stickerId`（用户）/ `AssistantSegment.kind==='sticker'` + `stickerId`（assistant）为准；Renderer 只走 `cyrene://renderer/__cyrene-media/sticker/{id}` 受控代理，不直接信任任意 `src`。

## 5. wire 边界修正（本批新增，spec §4.2 闭合项）

- **REST 边界：** `RestMessageSchema.duration_ms` `z.number().optional()` → `z.number().nullable().optional()`（`.strict()` 下接受 `null`，否则一页含 `duration_ms:null` 在 wire 层整页失败）；`rest-types.ts` `RestMessage.duration_ms` 同步为 `number | null | undefined`。
- **WS replay 边界：** `RawSessionMessageItemSchema.duration_ms` 同款 `z.number().nullable().optional()`（复验清单 §4.4「REST 首屏、getMessageContext、WS replay 三条恢复路径使用相同归一化语义」，否则 replay tool `duration_ms:null` 整段拒）；`raw-types.ts` `RawSessionMessageItem.duration_ms` 同步为 `number | null`。
- **领域/IPC 仍严格：** `MessageToolInfo.durationMs`（`number | undefined`）、IPC `MessageAttachmentSchema`/`AssistantSegmentSchema` 均不改；null 归一化只在映射层（`toOptionalNonNegativeNumber`），wire 放行 null、映射层转缺省、领域/IPC 不见 null。

## 6. `STICKER_ID_PATTERN` / src 兜底单一来源

- 单一来源在 **`shared/domain/sticker-url.ts`**（既有 `STICKER_ID_PATTERN` + `stickerIdFromResourceUrl`，已测：`new URL(url, 占位 origin).pathname` 末段剥 `.png` 再校验 `st_`，处理 `..` 归一化）。
- **content-part.ts 作 main 层门面**：import 并 re-export `STICKER_ID_PATTERN`；src 兜底委托 `stickerIdFromResourceUrl`，**不新增** `parseStickerIdFromSrc`（避免第三份解析拷贝）。
- **media-service.ts 经 import 消费**：本地同值 pattern 删除，改为经 content-part import——避免第三份拷贝与漂移。
- 真实 sticker src `/static/stickers/{id}.png` 形态由 `stickerIdFromResourceUrl` 正确解析（直接 `split('/').pop()` 得 `st_1.png` 会因 `.` 不符而永不命中，故必须委托既有函数）。
