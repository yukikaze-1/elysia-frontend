**日期：** 2026-08-29（Asia/Shanghai）
**性质：** UI 精修独立批次（非阶段 8 开工）。只改 Renderer 展示层，不触 Main/Preload/shared 契约。
**来源：** [UI 真机走查问题记录](2026-08-29-UI真机走查问题记录.md) 问题 3（表情按钮独占一行）与问题 4（输入区四键无层级）。
**约束基线：** [UI 精修整改清单](2026-08-29-UI精修整改清单.md)（红线 §1 总原则 / §2 布局 / §4 虚拟列表红线（不涉） / §7 可访问性 / §8 覆盖层层级 / §9 文案）。

## 1. 背景与目标

### 问题现象

- **问题 3：** 表情按钮（😊）独占输入框下方一行，突兀（`CyChatInput.vue:375-383` `.cy-composer-tools`）。
- **问题 4：** 输入框左侧四个同视觉权重图标（附件 / 普通录音 / 实时会话 / 转写）无分组无分隔，拥挤（`CyChatInput.vue:299-343` `.cy-composer-box`）。拥挤感来自**无层级**而非数量本身；且实时会话/转写属低频功能，与高频附件键同权重不合理。

### 目标布局

```
[+ 附件] [🎤 录音]  |  [😊 表情] [🔊 实时] [⌨️ 转写]   [textarea]  [停止] [发送]
   └── 输入一组 ──┘  │  └───── 附加功能一组 ─────┘
                    └ 细竖线 span（分组分隔）
```

- **组 1（输入）：** 附件、普通录音——高频内容输入两键。
- **分隔线：** 细竖线 span（`border-left` 类，宽 1px、高 24px、`background: var(--cy-border)`）。
- **组 2（附加功能）：** 表情、实时会话、转写——低频/娱乐三键。

### 设计意图

- 表情回归原型位置（原型 `ref/cyrene-ui-preview-v5.html` L2828-2831 中表情按钮本在 composer-box 内，与附件/录音/转写同行），解决问题 3。
- 用分隔线 + 功能分组界定两组，解决问题 4 的「无层级」。
- 按功能语义分组（输入 / 附加功能），非原型原始顺序（原型为 📎 🎤 😊 ⌨️，无实时会话 🔊）。

## 2. 改动点

**文件：** `apps/desktop/src/renderer/src/components/CyChatInput.vue`

### 2.1 模板：`.cy-composer-box` 内重排 + 插入分隔线 + 表情按钮归位

1. **组 1（附件 L300-302 + 录音 L305-319）** 保持原位。
2. **分隔线 span** 插在录音按钮（L319 `</button>`）之后、实时按钮（L320）之前：
   ```html
   <span class="cy-composer-divider" aria-hidden="true" />
   ```
3. **表情按钮组** 从 `.cy-composer-tools`（L375-383）整体移入，置于分隔线之后、实时按钮之前。原组结构（`cy-emoji-btn` + `cy-picker-wrap`）整体搬入，`@keydown="onPickerKeydown"`、`@click="showPicker = !showPicker"`、`:aria-expanded`、`.cy-emoji-pop` 定位锚点均不变。
4. **组 2 顺序确定为：** 表情 → 实时（L320）→ 转写（L331）。即表情在实时/转写之前。
5. **删除** 原 `.cy-composer-tools` 整块（L375-383）。

### 2.2 CSS

1. **`.cy-composer-box`（L441-450）：** grid 列数从 7 列改为……改用 flex？——**关键：**现在组内含分隔线元素，硬编码 `grid-template-columns` 列数会因元素增删而脆。**改用 `display: flex; align-items: flex-end; gap: 8px;`** 重置列数依赖（textarea 用 `flex: 1; min-width: 0`），保持现有视觉（同 baseline、同 gap、同圆角边框）。
   - textarea 当前 `width: 100%` 需改为 `flex: 1; min-width: 0`（否则 flex 列下宽度塌缩）。
2. **新增 `.cy-composer-divider`：** `width: 1px; height: 24px; background: var(--cy-border); align-self: center; flex-shrink: 0;`
3. **`.cy-emoji-btn`（L592-606）：** 迁入 box 后与 `cy-voice-btn`（32×32）统一为 `width: 32px; height: 32px;`（原 30×30），并补齐 `border: 1px solid var(--cy-border); background: var(--cy-surface);` 保持与 voice-btn 同视觉形状。
4. **删除 `.cy-composer-tools` 样式**（L585-590）：`display:flex; margin-top:7px; gap:8px` 那套——按钮进 box 后不再占独立一行。
5. **`.cy-picker-wrap`（L608-610）与 `.cy-emoji-pop`（L612-615）** 定位不变（`position:relative` + `position:absolute; bottom:100%; right:0`）——迁入 box 后仍相对 `.cy-picker-wrap` 锚定，成立。
