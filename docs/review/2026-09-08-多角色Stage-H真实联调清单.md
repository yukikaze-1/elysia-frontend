# 多角色 Stage H 真实联调清单

**建立日期：** 2026-09-08
**初始状态：** 待真实联调；本文不宣称任何一项已经验收
**联调范围：** Windows Electron + REAL `BackendAdapter` + `192.168.1.18` 上的真实后端
**契约基线：** `character-contract-v1`；后端冻结设计为 `elysia-agent/docs/2026-08-30-character-prompt-customization-backend-architecture-design.md`
**前端范围：** Stage H 静态对齐后的角色 REST/WS adapter、feature gate、角色目录/编辑器、会话选角、公开状态和身份守卫；不包含任务中心或阶段 8 发布验收

> 本清单是给实际执行者逐项记录的操作稿。所有检查项初始均为 `[ ] 待测`；没有预填 PASS、截图、响应或“已真实联调”结论。若某项需要后端调试夹具、只读 API 或开发者诊断入口而现场没有条件，应记录“阻塞/不可复现”，不能用 Mock 结果替代真实后端证据。

## 0. 记录规则与执行面

执行面标记：

- `UI`：当前 Windows Electron 可直接操作的真实界面。
- `API`：使用同一真实后端、同一认证凭据发起只读或契约规定的 REST 请求；请求/响应中不得记录 token、完整 Prompt 或用户自由文本。
- `DIAG`：设置 → 开发与诊断、Electron DevTools、脱敏诊断导出或受控 WS 抓帧。当前诊断页只展示连接状态、端点、协议/后端版本和脱敏事件，不直接展示两个 feature 布尔值或完整角色身份；缺少 UI 入口时必须保留原始 `server_info`/事件摘要作为证据。
- `BE`：后端提供的只读检查、迁移夹具或受控测试端点。前端当前没有 `revision_policy` 选择器，也不开放 instance create/clone；`pinned` 分支不能凭 UI 猜测通过。

每项至少记录：执行时间、Windows/Electron 构建或前端 commit、后端 commit/服务版本、配置的后端 URL、会话/角色/实例/版本 ID、请求 ID 或抓帧文件名、截图路径和结果。日志与截图必须脱敏。
