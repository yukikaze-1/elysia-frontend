## 4. 后续使用边界

1. 本清单**没有给 31 条前端主动记录排优先级**，也没有授权开始修复。
2. `V-*` 必须先取得当前版本证据；若无法复现或现有门禁已覆盖，应直接归档，不应为了“清单有一条”而改代码。
3. `X-*` 只有在重新开启条件满足后才回流；回流时要记录前后端 SHA、产品决定或外部凭证，避免凭印象重开。
4. `C-07` 是多个 Minor 的历史打包项，若以后进入修复，必须先拆分并逐个复核当前代码，不能整包提交。
5. 这份清单是阶段 1-7 的**运行债务 / 验收债务台账**，不是架构重构清单。RealBackend / MockBackend 体量、Preload/Main 装配集中度、Store 间依赖等架构议题如需推进，应另建架构清单，不能混入这 122 个历史编号。
