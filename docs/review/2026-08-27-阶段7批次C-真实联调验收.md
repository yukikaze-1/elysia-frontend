### ② 长会话消息列表 + 长流式/多分段 —— PASS（含 1 个真机缺陷修复）

- **缺陷发现**：56 条真实会话滚动到底后，最新 32 段回复的 DOM 不渲染。根因：`CyMessageList` 的虚拟垫片 `.cy-vlist-pad` 缺 `flex-shrink:0`，flex 布局把 `paddingTop/Bottom` 高度压成 0，`scrollHeight` 不含估算总高，无法滚动到新消息。
- **现场验证**：CDP 注入 `flex-shrink:0` 后 `scrollHeight 1522 → 8203`，最新回复立刻渲染出 31 个 `.cy-segment`。
- **修复 `c21413a`**：`CyMessageList.vue` 补 `.cy-vlist-pad { flex-shrink: 0 }`；`perf-gate` ③ 增加垫片 `flexShrink=0` + 至少一侧垫片高度 >0 的回归断言；`verify:sensitive` 补 7C 验收记录 commit SHA allowlist。
- **修复后真机复验**：同会话滚底，最新 assistant 行渲染（13 个 `.cy-segment` + 14 个 `.cy-markdown`），`scrollHeight 4984`，可视行 1，堆 32→33 MB。
- **真实流式路径**：修复前会话已捕获真实回复 **32 个独立段**、8.1s completed；修复后再次真实回复 **14 段**（store）+ DOM 全量呈现——真实 REST/WS 多分段路径正常。
- **长会话行有界**：50+ 条真实会话可视行 ≤15；`perf-gate` ③ mock 200 seed：`rows=19 padTop=4536px sh=5593`（垫片回归断言通过）。
