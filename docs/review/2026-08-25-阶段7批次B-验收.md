- **三态 = 已开发、未联调**。决策记录 §1/§7/§8.10 与任务 brief 均明示「真实 Windows Electron 联调为批次后」，全仓检索确认**无「已完成/已真实联调」误标**。
- 已知限制（接受档，spec §8）：
  - 崩溃二次触发不做风暴抑制（每次崩溃 reload 一次；防无限 reload 由 Main「reload 后检查 webContents 存活 + crashMarker 一次性清空」兜底）。

  - GPU 崩溃不自动 reload（Live2D 层经 webglcontextlost 间接 recover）。
  - 崩溃提示非实时 push（reload 后新 Renderer 经 getLastCrash 读取显示）。
  - 本批不做 UI 级 error boundary（只做进程崩溃），JS 异常兜底保留为观察项，7C/D 再评估。
