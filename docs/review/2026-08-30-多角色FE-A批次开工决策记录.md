## 1. 背景

`character-contract-v1` 已于 2026-08-30 与后端设计 §11～§12 冻结对齐（见设计文档 §19 冻结核对表）。按设计文档 §17.1 并行开工口径：后端推进 BE-A/BE-B/BE-C0（只做 `frontend_contract` DTO/事件/golden，feature 恒 false）的同时，前端 FE-A 可先行建立领域契约、strict schema 与兼容门，不依赖后端功能可用。阶段 8 仍为暂缓（见 [阶段 8 暂缓决策记录](2026-08-29-阶段8暂缓决策记录.md)），本批次按 doc 16 §5 规则以独立新批次运行。

## 2. 决策

FE-A 批次开工，范围严格限定为设计文档 §17「前端 A」八项：

1. **角色域领域契约**：新增 `shared/contracts/character.ts`（§5 全部类型 + §6.1 `CharacterBackendPort` 形状冻结，BackendAdapter 接线留给 FE-B）；`Page<T>` 复用既有 `contracts/conversation.ts` 定义，不重复声明。
2. **领域/IPC strict schema**：新增 `shared/schemas/character.ts`，全部 `.strict()`；`MessageSchema`/`ConversationSchema`/`ConnectionStateSchema` 接入 `character`/`features` 可选字段（不接入则 preload parse 静默剥字段，D6B-10 先例）。
3. **会话/消息 optional 快照**：`Conversation.character?`（绑定快照）、`Message.character?`（generation ref）、`CreateConversationInput.characterId?`。
4. **类型化能力**：`ConnectionState.features?: BackendFeatureFlags`；`parseBackendFeatureFlags` 只认 wire `=== true`，其余一律 false；仅 `connected` 状态填充，每次 server_info 整体替换（§5.2）。
5. **BackendEvent 扩展**：新增 `character.state.changed`/`character.catalog.changed` 领域事件与 schema 镜像；generation started/completed/failed 增加可选角色身份（CHAR-FE-08）；raw WS 帧与 `RawFrameSchema` 同步（RAW_FRAME_TYPES 36 型 → 38 型）。
6. **raw REST 层**：新增 `character-rest-types/schemas/mapper.ts` 三件套（自包含——`check:contract` 以裸 Node ESM 加载 rest-schemas.ts/raw-schemas.ts，运行时导入只允许 zod，registry ID/主题色校验函数三处镜像同步）；`RestSessionSummary`/`RestMessage` 增加可选 `character` 快照；mapper 做 null→undefined 归一（§5.4 冻结约定：整个角色域统一归 undefined）与 `{items,has_more,cursor?} → Page<T>` 分页映射。
7. **持久化兼容**：`SessionPersistenceState` 经既有 Conversation/Message schema 内嵌自动获得角色快照，无独立 shape。
8. **契约门禁工具**：`check-backend-contract.mjs` 支持环境变量 `CYRENE_FRONTEND_CONTRACT_DIR`（或首个 CLI 参数）指定 handoff bundle 目录、`CYRENE_FRONTEND_CONTRACT_TRACES` 指定 traces（不再硬编码单一 Linux 路径）；新帧纳入 `WS_V2_FRAME_TYPES` 白名单（35 → 37 型）。

**schema 变更同步动作**：`RawFrameSchema` 变更后以 `scripts/refresh-wire-manifests.mjs` 刷新全部 14 个 wire fixture manifest 的 `schemaHash`（指纹门禁保持闭环）。

## 3. 有意的暂定值（handoff 对拍前不得放宽）

- `CHARACTER_LIMITS`（displayName/aliases/examples/prompt 字段等数量与长度上限）为前端从严暂定值；设计文档要求与后端「同等或更严」但未给出数字，拿到 BE-C0 handoff bundle 后按 `contract.schema.json` 对拍修正。
- 注册表 ID 拒绝绝对路径/盘符/URL/`..`；`themeColor` 只收 hex/rgb(a)/hsl(a)/CSS 命名色（§6.4 fail-closed）。
- wire 层 `mood/currentActivity/lastInteractionAt/presentation.*` 接受 `null`（诚实反映后端可空），领域层一律归一 `undefined`。
