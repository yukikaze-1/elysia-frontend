# P0-7 的 asar 与产物完整性半边：范围解除决策记录

**日期：** 2026-09-12
**状态：** 已决（范围解除，附恢复条件）
**影响范围：** doc 16 §4.1／§5.4；doc 09 发布矩阵与 doc 12 §4.7 G-01（均为引用关系，不改其设计）
**性质：** 同日 `EXT-01` 范围解除记录的**补正与收口**——它处置的是 P0-7 的另一半

## 1. 触发问题

评审的 P0-7 行含**两项**要求（`docs/review/2026-09-11-full-frontend-review.md` P0-7 行）：

1. `EXT-01`（第三方资产授权与来源）；
2. `asar: false` 的处置——**评估 `asar: true`，或为 `resources/app/**` 补 SHA-256 清单**，并由 `verify-artifact.cjs` 校验。

2026-09-12 的[个人使用范围与阻塞解除决策记录](2026-09-12-EXT-01-个人使用范围与阻塞解除-决策记录.md)处置了第 1 项，并写下「`P0-7` 随之解除。**它原本只依赖 `EXT-01`**，现无待办」——该前提与评审该行的定义不符：第 2 项既未处置、也未在该记录里被一并声明解除。doc 16 据此写成「P0-7 亦已解除」。

本轮按实测把 doc 16 更正为「`EXT-01` 半边已解除；asar/完整性半边**未做**且未被任何记录一并解除」，并立本记录给出结论。本记录**不改写**上述历史主张，只补正其范围。

## 2. 实测事实（2026-09-12，只读核对）

| 项 | 实测 |
|---|---|
| 打包形态 | `apps/desktop/electron-builder.yml:9` 仍为 `asar: false` |
| 完整性校验 | `apps/desktop/scripts/verify-artifact.cjs` 内**无** `resources/app/**` 的 SHA-256 清单或等价校验；其现有断言为 CSP／自定义协议／Vue 挂载／计算样式（冒烟）与**三个 fuse** 的 wire 读回必须 DISABLE |
| 已校验的三个 fuse | `RunAsNode`、`EnableNodeOptionsEnvironmentVariable`、`EnableNodeCliInspectArguments`（同文件 :117-119） |
| 未启用的两个 fuse | `EnableEmbeddedAsarIntegrityValidation`、`OnlyLoadAppFromAsar`——在 `asar: false` 下**无从启用** |
| 后果 | 产物中的应用代码（renderer bundle、main／preload、`resources/app/**` 整棵）在磁盘上被替换时，现有门禁**不会变红** |

**边界（避免误读本记录）**：已校验的三个 fuse 管的是 **node 子进程执行面／`NODE_OPTIONS` 注入面／`--inspect` 调试参数**，与 asar 完整性是**两件事**。本次解除**不影响**它们继续硬性 DISABLE，也不改动任何既有门禁。

## 3. 决策

**解除 P0-7 的 asar/完整性半边**，依据与 `EXT-01` 相同且已由用户明确：本项目仅供本人自用，所谓"发布"即本人自己安装 ⇒ 产物完整性所保护的**消费者（对外分发的产物）在当前使用范围下不存在**。

- 与本仓库纪律一致：本记录**只主张"该风险的触发面没有实例"**，**不主张"已安全""已合规"**；第 2 节的实测事实全部继续成立。
- **不计入"已实现"**：doc 16 只记「范围解除」，不得把 asar 或 SHA-256 清单写成已完成项，也不得把该项从评审条目里删除——评审报告按纪律原样保留。
- 不因解除而放宽任何门禁；三 fuse 读回仍在 CI 的 Linux `packaged artifact smoke` 与 `windows build-level` 两个 job 中执行，`verify:artifact --smoke` 照旧。

## 4. 恢复条件（出现任一即原样恢复）

1. **对外分发**：除本人之外的任何人安装；
2. **多人使用**同一份产物；
3. **接入自动更新**（更新链会引入替换产物的外部路径）；
4. **上架**任何商店或分发渠道。

恢复内容 = 评审 P0-7 第 2 项的原始要求：评估 `asar: true`，**或**为 `resources/app/**` 补 SHA-256 清单并在 `verify-artifact.cjs` 中校验。

**已知代价（恢复时须知）**：`asar: true` 会改动运行时文件布局，牵动 Live2D 模型路径解析与 `__dirname` join——评审原文把该项复杂度标为 **L**，恢复时应先做该项评估而不是直接切换。
