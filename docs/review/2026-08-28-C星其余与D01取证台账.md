## 1. 已落地项

### C-04②（#7）Live2D adapter 重复模型销毁 → **落地**
- **缺口：** `adapter.ts:622` `this.handle = handle` 直接覆盖旧 handle 未先 destroy——若调用方绕过 controller 直调 adapter 会泄漏（moc/model/renderer 未释放）。controller 层 `switchModel` 先 destroy 兜底，但 adapter 边界缺纵深。
- **修复：** 覆盖前补 `this.handle?.destroy()`。**TDD：** `live2d-adapter.spec.ts` 新增——二次 createModel 后前一个 `moc.deleteModel`/`moc.release` 被调，新 handle 可用。

### C-04③（#7）createModel 异步期 GPU-lost 探测 → **落地**
- **缺口：** createModel 入口检查（:521/:527）后、多个 await（model3/moc/纹理）期间无 `isContextLost` 复查——context 若在这些 await 中丢失，模型会基于已丢 context 完成创建。`update()` 的探测只在渲染 tick 生效。
- **修复：** 创建 GL 资源（renderer 构造）前补 `if (this.gpuLost || this.engine.isContextLost(gl)) throw new Live2DGpuLostError()`。**TDD：** `live2d-adapter.spec.ts` 新增——自定义 fetch 在 model3 后 `setContextLost(true)`，断言 createModel 抛 `Live2DGpuLostError` 且未创建 renderer。

### C-10（#18）非 Error 抛掷错误归一 → **落地（log-only 防御）**
- **缺口：** 2 处 `(e as Error).message` 残留——`real-backend.ts:305`（tool.request:parse-failed）、`grant-store.ts:65`（grant:save-failed）。非 Error 抛掷 → `undefined`。全仓其余已用 `instanceof Error`。
- **修复：** 两处改 `e instanceof Error ? e.message : String(e)`。**仅日志准确性**，不涉产品行为。

### C-14（#29）补齐未定义 cy-bg tokens → **落地**
- **缺口：** `tokens.css:root` 未定义 `--cy-bg`/`--cy-bg-sub`/`--cy-bg-muted`/`--cy-text-muted`/`--cy-text-secondary`，但四组件（CyToolCard/CyToolApproval/CySecurityPane/CyDiagnosticsPane）引用（无 fallback）——引用落空，样式回退浏览器默认。
- **修复：** tokens.css 补齐 5 个 token，映射到既有 surface/muted 系（`--cy-bg: var(--cy-surface)` 等），light-dark 一致。收口四组件同款写法。

### D-01（#25）read 权限窗验收措辞 → **落地（文档）**
- **缺口语径：** 阶段 6 验收清单 2.3「read 权限窗」写成「后续 `desktop.file.read{path=…}` → 卡片 `awaiting_permission`」，但实测 select 返回路径命中 selected-set 豁免直接执行（见 2.5），不弹窗。
- **修复：** 验收清单 2.3 措辞补「**未预选直接路径**」限定 + 注「select 路径命中 2.5 selected-set 豁免直接执行，不弹窗」——与实际授权路径一致。
