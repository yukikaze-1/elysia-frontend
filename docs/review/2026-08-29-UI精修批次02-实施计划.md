# UI 精修批次 02 Implementation Plan —— 输入区交互重设计

> **For agentic workers:** 实施按 task 逐个执行（writing-plans 纪律）。每 task 有独立可测交付物 + 提交点。
> 设计依据：[2026-08-29-UI精修批次02-输入区交互重设计.md](/home/yomu/elysia-frontend/docs/review/2026-08-29-UI精修批次02-输入区交互重设计.md)

**Goal:** 输入区从「5 同权重按钮」重设计为「6 常驻控件 + 实时语音独立胶囊」，统一语音入口（转录主键+下拉菜单），附件弹菜单按 accept 分类。

**Architecture:** 只改 `CyChatInput.vue`（模板 + CSS + 少量内联弹出状态）。store 语义全不动。新增两个内联下拉菜单（附件菜单 + 语音菜单），实时语音从主行移到框外 accent 胶囊。

**Tech Stack:** Vue 3 `<script setup>` + scoped CSS + tokens.css 令牌。无新依赖。

**Spec:** `docs/review/2026-08-29-UI精修批次02-输入区交互重设计.md`

## Global Constraints

- §2 布局硬限制：标题栏 36px / 导航 60px / 会话列表 260px / Live2D 340px / 聊天最小 500px / 最小窗 1100×700 / 断点 1200/736/520/320 —— 不动。

- 颜色/圆角/阴影走 `tokens.css` `--cy-*`；不硬编码颜色；新值同时给 light/dark。
