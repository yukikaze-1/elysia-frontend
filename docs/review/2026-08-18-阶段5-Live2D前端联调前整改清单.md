## 1. F-1【P0·联调前必须改】真实 emotion 到情绪态的归一映射

### 1.1 问题

后端 `generation.completed.mood` 是 **LLM 自由文本**，真实值如 `开心`、`平静`、`难过`（上一轮阶段 4 真实日志已见 `心情: 平静 → …`）。前端当前只认英文枚举码：

```ts
// apps/desktop/src/renderer/src/live2d/state-source.ts
const KNOWN_MOODS: ReadonlySet<string> = new Set<MoodEmotion>(['happy', 'sad', 'surprised'])
```

因此真实后端回 `mood="开心"` 时不会进入 `happy`，联调清单 **C3-1（真实 emotion→情绪→表情路径）会失败**。Mock 测试全部使用英文 `happy/sad/surprised`，掩盖了该跨仓差异。

### 1.2 整改内容

在 `live2d/state-source.ts` 增加一个纯函数 `normalizeEmotionCode(raw: string | undefined): MoodEmotion | undefined`，在 `composeCharacterState` 前归一：

| 目标态 | 接受值（不区分 ASCII 大小写，中文按字面匹配） |
|---|---|
| `happy` | `happy`、`开心`、`高兴`、`愉快`、`喜悦`、`兴奋` |
| `sad` | `sad`、`难过`、`悲伤`、`伤心`、`沮丧`、`低落` |
| `surprised` | `surprised`、`惊讶`、`惊喜`、`吃惊`、`诧异` |

约束：

- 只做本地归一，不把未知码当动作/表达式名；
- `平静`、`neutral` 等未命中值保持 `undefined` → 落 `idle`，行为不变；
- 归一逻辑与 `CyLive2DPanel` 的中文徽标（`happy→开心`）不重复维护：徽标继续按目标态显示。

### 1.3 必须补的测试

- `tests/unit/live2d-state-source.spec.ts`：
  - `composeCharacterState(... emotion:'开心') === 'happy'`
  - `emotion:'难过' === 'sad'`；`emotion:'惊讶' === 'surprised'`
  - `emotion:'平静' === 'idle'`
  - 英文码回归不破坏
- `tests/unit/live2d.spec.ts`：
  - `injectCompletedMessage('开心')` 后 store 推送 `setState('happy')`
  - `injectCompletedMessage('平静')` 仍为业务态/idle
- 集成或 mock 链路：
  - `CYRENE_MOCK_GENERATION_EMOTION=开心` 时，状态徽标显示“开心”且画布非空（如现有英文 happy 用例同路径）
- 真实后端 fixture：
  - 增加 `generation.completed.mood="开心"` 的 raw fixture，确认 FrameMapper → `emotion='开心'` → 归一 `happy`

## 2. F-2【P0·环境准备】前端代码与模型基线同步

### 2.1 代码同步

- 本地 `main` 领先 `origin/main` 12 个提交，HEAD `8f7dd94`；
- 联调前必须 push，并让 Windows 机器 `git rev-parse HEAD` 等于最终前端 SHA（F-1 修复后会产生新提交，以修复后 HEAD 为准）；
- Windows 启动命令保持 REAL 模式；不要用 Mock 替代。

### 2.2 模型安装

联调清单要求的模型基线为 `haru` / `lil` / `wanko`。当前 Linux `userData/models` 只有 `haru` 与 `lil`，**缺 `wanko`**；Windows 侧需另行安装。

```bash
pnpm -F @cyrene/desktop live2d:install \
  --model-dir third_party/CubismSdkForWeb-5-r.5/CubismSdkForWeb-5-r.5/Samples/Resources/Haru \
  --id haru --display-name Haru

pnpm -F @cyrene/desktop live2d:install \
  --model-dir third_party/CubismSdkForWeb-5-r.5/CubismSdkForWeb-5-r.5/Samples/Resources/Wanko \
  --id wanko --display-name Wanko

# lil 为可选用户模型（8192 纹理，SwiftShader 下可能装载失败）；
# 如 Windows 真机有模型源，按联调清单装配：
pnpm -F @cyrene/desktop live2d:install \
  --model-dir <lil 源目录> --id lil --display-name 修女莉尔
```

验收：

- 设置页列出至少 `haru`、`wanko` 且 `available=true`；
- `haru` 可加载；`wanko` 可切换；`lil` 若装配，记录 8192 纹理真机结果。
