# UI 精修整改清单（规则与限制）

**日期：** 2026-08-29（Asia/Shanghai）
**性质：** 阶段 8 之前独立 UI/布局/风格精修批次的约束基线。只读规则，不修改代码。
**适用范围：** Renderer 视觉与交互改动；不涉及 Main/Preload/shared 契约。
**当前状态源：** [doc 16](../16-Cyrene-前端实施任务清单与进度跟踪.md)；设计基线 [doc 03](../03-Cyrene-前端UI与交互设计-v0.2.md)。

---

## 1. 总原则

1. UI 精修是**独立批次**，不得标记为阶段 8 开工。
2. 只改 Renderer 展示层：组件、样式、布局、文案。不得借机改 Main/Preload、IPC、契约、存储格式。
3. 功能语义不回退：连接状态、流式渲染、工具卡、附件、语音、Live2D 折叠、诊断导出等既有行为保持。
4. 所有视觉值走 `tokens.css`；新增 token 必须同时给 light/dark 两套，禁止硬编码颜色。
5. 每个视觉改动都要能在 1100×700 最小窗口和 1200/736/520/320 四档断点下自解释，不依赖“用户把窗口拉大”。

## 2. 布局硬限制（不可改，除非先改 doc 03 + layout 常量 + 单测）

来源：`renderer/src/layout/constants.ts`、`effective-layout.ts`、doc 03 §3。

| 项目 | 固定值 |
|---|---|
| 标题栏高度 | 36px |
| 导航栏宽度 | 60px |
| 会话列表宽度 | 260px，可折叠 |
| Live2D 默认宽度 | 340px，可调范围 [300, 420] |
| 聊天区最小宽度 | 500px |
| 最小窗口 | 1100 × 700 |
| 断点 | 1200 / 736 / 520 / 320 |

约束：

- Live2D 是**布局列**，禁止用悬浮层盖住消息、滚动条或输入区。
- 窄窗折叠顺序：先会话列表，仍不够再自动关闭 Live2D；聊天区优先保护。
- 布局计算只依赖 `computeEffectiveLayout` 纯函数；组件里不要另写一套宽度判断。
- 布局记忆仍是 `localStorage` 键 `cyrene.layout.v1`；改结构需要显式迁移，不能静默覆盖用户偏好。
- CSS 需要引用区宽时经组件注入 CSS 变量，不要复制 60/260/340/500 等魔数。

## 3. 滚动与滚动条（当前已知问题：聊天区滚动条闪烁）

- 聊天消息区、会话列表、历史查看器、设置内容区各自独立滚动；不要引入嵌套滚动导致外层跟着滚。
- 滚动容器应预留滚动条空间，禁止滚动条出现/消失造成内容横向跳动。优先使用：
  - `scrollbar-gutter: stable;`
  - 或固定自定义滚动条宽度 + 容器不因 `overflow` 状态变化改宽度。
- 不要用 `overflow: hidden` 掩盖溢出后丢失滚动能力；长会话/长设置页必须可滚。
- 历史查看器保持 `overflow-anchor: none`（loadMore 锚点补偿依赖它）。
- 保留「回到底部」按钮的出现/隐藏逻辑和 `atBottom` 判定，视觉重做不能破坏滚动位置恢复。

## 4. 消息列表与历史查看器（虚拟列表红线）

受 perf-gate 保护的 DOM 契约，以下类名/结构不能删除或改名，除非同步改测试和 perf-gate：

- `.cy-vlist-row`、`.cy-vlist-pad`、`data-message-id`
- `.cy-segment`（assistant 分段）
- `.cy-history-item`、`.cy-history-results`
- `.cy-response-head`、`.cy-response-cluster`、`.cy-muted` 状态文案
- `.cy-back-bottom`、`.cy-streaming-placeholder`、`.cy-sr-live`

约束：

- `.cy-vlist-pad` 必须保留 `flex-shrink: 0`（7C 真机修复）。
- 行高改动会影响 `estimateMessageHeight` / `onRowResized` 前缀和：改气泡 padding、字号、行高后必须跑 perf-gate ②/③。
- 不能为了让列表“更好看”绕过虚拟化全量渲染；perf-gate 硬线：可视 DOM 行/项 ≤ 60。
- 视图感知暂停逻辑（视口外 completed segment 空 source）依赖 strict 窗口；不要改 `.cy-vlist-row` 的 padding 而不复核。
- 流式新增分段允许有 80ms 防抖渲染，视觉上不要为“消除瞬间空段”引入整条重排。

## 5. Live2D 右栏

- 保持右栏作为 grid 列；折叠/隐藏用既有 `layout.effective.live2dShown`，不要改成覆盖层。
- 折叠、进 settings/tasks 后 rAF 必须停止（`currentView` gate）；不要给常驻挂载面板加后台动画。
- 画布尺寸由 ResizeObserver 自缓冲；改栏宽/内边距后要验证 canvas 实际渲染尺寸和非透明像素。
- `reduceMotion` 开启时禁用鼠标跟随/点击动作；UI 动画也应尊重该设置。
- 状态徽标、模型选择、缩放/偏移手柄是功能面，不是纯装饰。

## 6. 主题与 token

- 颜色、字体、圆角、阴影统一走 `tokens.css` 的 `--cy-*`；组件 scoped 样式不得另起颜色。
- 新增 token 规则：
  - 颜色用 `light-dark(light 值, dark 值)`；
  - 先复用既有 token，避免同色多名；
  - 修改既有 token 前搜索全部引用，并检查工具卡/安全页/诊断页等跨组件影响。
- 字体基准 `--cy-font-base: 14px`，用户缩放 `--cy-user-font-scale`；不要用固定 px 绕过字号缩放。
- 亮/暗两套都要真机截图检查；系统主题由 `color-scheme: light dark` 驱动，不要引入第二套主题切换状态。

## 7. 可访问性与键盘

- 不删除/改坏：焦点样式、`aria-label`、`aria-live` 区域、设置页焦点陷阱、Esc 关闭、IME 输入。
- 状态不能只靠颜色区分；保留现有文字/图标/chip（连接状态、消息状态、工具状态）。
- 对比度满足亮暗两套；muted 文本只用于次要信息，不用于关键状态。
- 用户可选择文本的位置不得改成 `user-select:none`（正文、错误信息、工具结果摘要可复制性需保留；现有 body 默认不可选只用于界面，不改散）。
- 高亮定位「已定位」chip + aria-live 语义保留，不能只做颜色高亮。

## 8. 覆盖层、弹窗与层级

- 标题栏下覆盖层保持 `inset: 36px 0 0 0`，z-index 层级：
  - 普通 toast：40；
  - 设置中心：50；
  - Live2D/聊天主体不得高于覆盖层。
- 设置/历史查看器内部滚动归内容区，面板整体不得溢出窗口。
- 权限确认、Diff 预览、文件选择等原生/覆盖层流程只改视觉容器，不改关闭/确认语义。
- 崩溃 banner 全局挂载位置保留；修复 C-16 轻微截断时不能把 banner 改为覆盖消息。

## 9. 文案与占位清理（可纳入本次精修）

- 「任务中心 · 阶段 6 落地」占位：阶段 6 已完成，改为正式空态/入口语义，或明确 defer 到阶段 8。
- 设置导航 note 的「阶段4 P4-A/P4-B」等旧阶段标签应清理为当前语义。
- C-01（聊天头部窄宽度视觉微调）、C-16（崩溃横幅轻微截断）可从归档重新纳入本次视觉批。
- 修改文案时同步检查对应单测/集成测试的选择器，避免因按钮名变化红测。

## 10. 性能红线

- 不引入全量重渲染：消息/历史继续虚拟化。
- 动画只用 transform/opacity，避免 layout/paint 抖动；长列表滚动不挂 `box-shadow`/`filter` 大开销层。
- Live2D 折叠后 rAF=0 的 perf-gate ④必须继续通过。
- 诊断导出、历史查看器打开等路径的内存观察保持在既有 30–47 MB 量级。
- 不新增第三方 UI/动画库；保持当前依赖边界。

## 11. 验证清单（提交前）

1. `pnpm docs:check`
2. `pnpm typecheck`
3. `pnpm lint`
4. `pnpm test`
5. `pnpm test:integration`（重点 perf-gate、electron-live2d、navigation、settings）
6. `pnpm build`
7. `pnpm --filter @cyrene/desktop start` 同源形态人工检查：
   - 亮/暗两套；
   - 1100×700 + 四档断点；
   - 长会话滚动 + 滚动条不闪烁；
   - Live2D 展开/折叠、设置页模型切换；
   - 历史查看器加载更多；
   - 工具卡、权限、诊断页。
8. `pnpm -F @cyrene/desktop check:contract`、`verify:sensitive` 按范围执行。
