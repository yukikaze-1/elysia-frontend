## 1. 总原则

1. UI 精修是**独立批次**，不得标记为阶段 8 开工。
2. 只改 Renderer 展示层：组件、样式、布局、文案。不得借机改 Main/Preload、IPC、契约、存储格式。
3. 功能语义不回退：连接状态、流式渲染、工具卡、附件、语音、Live2D 折叠、诊断导出等既有行为保持。
4. 所有视觉值走 `tokens.css`；新增 token 必须同时给 light/dark 两套，禁止硬编码颜色。
5. 每个视觉改动都要能在 1100×700 最小窗口~~和 1200/736/520/320 四档断点~~下自解释，不依赖“用户把窗口拉大”（**四档断点已撤销，见 §2 取代注记**）。

## 3. 滚动与滚动条（当前已知问题：聊天区滚动条闪烁）

- 聊天消息区、会话列表、历史查看器、设置内容区各自独立滚动；不要引入嵌套滚动导致外层跟着滚。
- 滚动容器应预留滚动条空间，禁止滚动条出现/消失造成内容横向跳动。优先使用：
  - `scrollbar-gutter: stable;`
  - 或固定自定义滚动条宽度 + 容器不因 `overflow` 状态变化改宽度。
  > **落地状态（2026-09-15 收口）：四容器已全部加上 `scrollbar-gutter: stable`。** 此前只有 2 处
  > （`CyMessageList.vue` 的 `.cy-messages`、`CyProfileWizard.vue` 的 `.cy-wizard-body`），本节点名的
  > **会话列表**（`.cy-conversations`）、**历史查看器**（`.cy-history-results`）、**设置内容区**
  > （`.cy-settings-body`）三处均缺——2026-09-14 review 记为「代码不足、文档对」，2026-09-15 裁决
  > 「补代码」并已补齐。⇒ 本节该条从「已知缺口」转为**已满足**；若新增滚动容器，仍须自查此条。
- 不要用 `overflow: hidden` 掩盖溢出后丢失滚动能力；长会话/长设置页必须可滚。
- 历史查看器保持 `overflow-anchor: none`（loadMore 锚点补偿依赖它）。
- 保留「回到底部」按钮的出现/隐藏逻辑和 `atBottom` 判定，视觉重做不能破坏滚动位置恢复。

## 5. Live2D 右栏

- 保持右栏作为 grid 列；折叠/隐藏用既有 `layout.effective.live2dShown`，不要改成覆盖层。
- 折叠、进 settings/tasks 后 rAF 必须停止（`currentView` gate）；不要给常驻挂载面板加后台动画。
- 画布尺寸由 ResizeObserver 自缓冲；改栏宽/内边距后要验证 canvas 实际渲染尺寸和非透明像素。
- `reduceMotion` 开启时禁用鼠标跟随/点击动作；UI 动画也应尊重该设置。
- 状态徽标、模型选择、缩放/偏移手柄是功能面，不是纯装饰。

## 6. 主题与 token

- 颜色、字体、圆角、阴影统一走 `tokens.css` 的 `--cy-*`；组件 scoped 样式不得另起颜色。
- 新增 token 规则：
  - 颜色用 `light-dark(light 值, dark 值)`；
  - 先复用既有 token，避免同色多名；
  - 修改既有 token 前搜索全部引用，并检查工具卡/安全页/诊断页等跨组件影响。
- 字体基准 `--cy-font-base: 14px`，用户缩放 `--cy-user-font-scale`；不要用固定 px 绕过字号缩放。
- 亮/暗两套都要真机截图检查；系统主题由 `color-scheme: light dark` 驱动，不要引入第二套主题切换状态。

## 7. 可访问性与键盘

- 不删除/改坏：焦点样式、`aria-label`、`aria-live` 区域、设置页焦点陷阱、Esc 关闭、IME 输入。
- 状态不能只靠颜色区分；保留现有文字/图标/chip（连接状态、消息状态、工具状态）。
- 对比度满足亮暗两套；muted 文本只用于次要信息，不用于关键状态。
- 用户可选择文本的位置不得改成 `user-select:none`（正文、错误信息、工具结果摘要可复制性需保留；现有 body 默认不可选只用于界面，不改散）。
- 高亮定位「已定位」chip + aria-live 语义保留，不能只做颜色高亮。

## 10. 性能红线

- 不引入全量重渲染：消息/历史继续虚拟化。
- 动画只用 transform/opacity，避免 layout/paint 抖动；长列表滚动不挂 `box-shadow`/`filter` 大开销层。
- Live2D 折叠后 rAF=0 的 perf-gate ④必须继续通过。
- 诊断导出、历史查看器打开等路径的内存观察保持在既有 30–47 MB 量级。
- 不新增第三方 UI/动画库；保持当前依赖边界。
