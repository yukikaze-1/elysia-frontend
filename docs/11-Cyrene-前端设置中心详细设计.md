## 2. 模型服务

### 2.1 Profile

```typescript
interface ModelServiceProfile {
  id: string;
  type: "llm" | "stt" | "tts";
  displayName: string;
  source: "built_in" | "custom";
  provider: string;
  model: string;
  protocol: "openai_compatible" | "custom_rest" | "local_worker" | "bundled_local";
  executionLocation: "backend" | "desktop" | "local_worker";
  endpoint?: string;
  credentialOwner: "backend" | "desktop_main" | "local_worker" | "none";
  credentialStatus: "missing" | "configured" | "expired";
  enabled: boolean;
  capabilities: string[];
  updatedAt: string;
}
```

前端只读取凭据状态。新建或更新密钥时使用一次性提交接口，保存成功后立即从表单状态清除明文。

### 2.2 LLM 设置

- Provider；
- Endpoint 或后端配置名称；
- 模型；
- 凭据状态；
- 上下文长度等只读能力摘要；
- 测试连接；
- 短推理测试；
- 设为当前 LLM；
- 公开错误和延迟。

测试结果不得把测试提示、完整回复或密钥写入普通日志。

### 2.3 STT 设置

- Provider、模型和执行位置；
- 支持语言；
- 是否支持普通录音识别、实时字幕和输入法转写；
- 测试麦克风；
- 录制短音频并测试转写；
- 设为当前 STT；
- 显示延迟、转写文字和错误。

> **阶段 4 批次 B 落地（2026-08-16，语音子页 `CyVoicePane`）：** 测试麦克风已实现——录 3s 后本地 AudioContext 试听 + 时长显示 + 错误显示（权限拒绝/无设备）；**转写测试复用 dictation 链路（用户实际输入时自然验证，不做专用入口）**。

### 2.4 TTS 设置

- Provider、模型、声音和执行位置；
- 语言、采样率和流式能力摘要；
- 试听；
- 音量与语速；
- 设为当前 TTS；
- Live2D 口型兼容状态。

### 2.5 自定义模型

模型服务页提供“添加自定义模型”，LLM、STT、TTS 共用向导，但按类型显示不同能力字段。输入法转写不创建第四种模型服务，而是从兼容 STT Profile 中单独选择。

必填项：

- 类型、显示名称、模型 ID；
- 兼容协议与模型执行位置；
- 远程模型填写 HTTPS Endpoint，本地模型填写已注册的 Local Worker；
- 至少声明一个与类型匹配的能力。

可选项：Provider 名称、API 版本、组织/项目头、上下文长度、语言、实时转写、声音、采样率、流式能力和请求超时。自定义 Header 只能使用允许名单，禁止保存 Cookie、Host、代理认证等危险字段。

Endpoint 安全规则：远程 Provider 默认只允许 HTTPS；需要连接 `localhost/127.0.0.1/[::1]` 的本地模型时必须选择“本机 Provider”模式，并明确显示实际目标和 HTTP 风险。Main 需要校验 DNS、实际连接地址、重定向和域名黑名单，默认拒绝云元数据、链路本地、未授权私网及跨域携带密钥。测试按钮只发送固定最小样例，不使用真实聊天、文件或录音。

流程：填写 → 本地校验 → 一次性提交凭据 → 类型化能力测试 → 保存 Profile → 可选立即设为当前模型。测试必须使用最小数据，失败时保留表单并给出可执行错误；未经用户确认不能因为测试失败自动改用其他服务。

编辑自定义 Profile 时不回填密钥。删除前检查是否为当前 Profile、回退链或会话固定模型；内置 Profile 不允许删除，只允许禁用。

### 2.6 输入法转写的 STT 选择

输入法转写用于“按住说话 → 松开 → 文字进入聊天框”的输入辅助，与普通录音输入和实时语音会话分开配置。它复用 STT Profile 的 Provider、能力测试和凭据，但拥有独立选择 ID，因此可以和直接语音输入使用不同模型。

- 使用独立的 `dictationSttProfileId`、语言和插入位置设置；
- 只列出声明支持听写/最终转写的 STT Profile；
- 执行位置由选中的 STT Profile 决定，可为 Backend、本机或 Local Worker；
- 测试动作录制一段短音频，只验证最终文字、延迟和取消能力；
- 后端执行必须在设置和首次使用时说明音频会上传；本机/Local Worker 必须展示模型下载、可用性或资源占用；
- 转写结果只进入草稿，不自动发送、不创建语音消息；原始音频默认不保留；
- 删除被输入法转写使用的 STT Profile 前，必须先选择替代项或关闭输入法转写。

> **阶段 4 批次 B 落地（2026-08-16，语音子页）：** 转写专用 STT 下拉已实现——数据源 `modelServiceStore.profiles` 过滤 **`type==='stt' && enabled && executionLocation==='backend'`**（D-P20：desktop/local profile 会 `STT_PROFILE_NOT_FOUND`，不列），绑 **`settingsStore.dictation.sttProfileId`**（本地设置，D-P14，非激活选择数据源），含「使用全局活动 STT」空选项；**删除被转写引用的 STT Profile → 自动清空 `dictation.sttProfileId`（回退全局活动 STT）+ toast**。转写插入位置仅 `追加草稿末尾 / 替换当前选区`（`dictationInsertMode` 两值，D-P4）——**「光标级插入」列为后续**（P4-B 子集）。

### 2.7 切换规则

- 切换只影响新请求，不强行中断当前生成、转写或播放；
- 当前 Profile 不可用时提示用户选择，不静默切换到会上传数据的模型执行位置；
- 若配置允许自动回退，必须显示回退顺序和数据去向；
- 删除当前 Profile 前要求先选择替代项；
- 测试失败不自动禁用历史可用 Profile。

## 3. 语音输入

### 3.1 普通模式

```text
点击麦克风 → 请求权限 → 录音 → 停止 → 生成待发送语音输入 → 用户确认发送
```

录音停止后不自动发送。用户可以试听、删除、重新录制或确认发送。若启用 STT 字幕，识别文字只作为该语音输入的字幕/辅助信息，不写入文字输入框。

**停止后等待 STT 终态（阶段 4 真实联调整改，R-S4-04/R-S4-07）：** 停止后进入「正在识别…」等待态（`record.awaitingTranscript`）——等 `voice.transcript` 或 `voice.error` 任一终态；仅真实 45s 超时兜底（后端自动回 IDLE、无终态信号）才翻转「未识别，请重试」。等待期**试听/删除/重录可用、确认发送禁用**（无字幕不可发送）；错误与字幕可并存展示（`CyVoicePending` 渲染：错误与字幕相互独立可并存，「正在识别…」/「未识别，请重试」仅在无字幕且无错误时出现）。「删除/重录」经 `voice.discard` 取消——**可取消任意未提交阶段（RECORDING/TRANSCRIBING/PENDING）且幂等成功**（IDLE 迟到/重复 discard 亦成功），是唯一取消原语：不要求先 stop、不调 STT、不产 transcript（R-S4-01，依赖配套后端修订 BE-S4-RUN-P0-01）。

### 3.2 实时模式

```text
点击实时语音 → 建立语音会话 → 传输音频 → partial/final 字幕 → VAD/用户确认提交语音轮次 → 停止
```

- partial 使用临时字幕样式，final 形成稳定字幕；
- partial/final 都不得合并进文字草稿；
- `sequence` 防止重复和乱序；
- 静音自动断句和是否自动提交语音轮次必须分别配置；
- STT 字幕断开不应自动终止仍可继续的语音会话；
- 切换会话前提示处理当前语音会话。

### 3.3 设置项

- 启用语音输入；
- 启用实时语音；
- 麦克风设备；
- STT Profile；
- 语音活动检测；
- 静音结束时长；
- 输入语言或自动识别；
- 是否保留录音：默认不保留。
- 是否显示直接语音字幕；
- 实时语音自动断句和语音轮次提交规则。

### 3.4 按住说话转文字

- 可独立启用或关闭；
- 单独选择输入法转写专用 STT Profile；
- 支持按住录音、滑动/按键取消、松开提交转写；
- 最终文字写入当前光标位置并保持可编辑；
- 切换会话、窗口失焦或权限撤销时安全取消，不把残余音频发送到其他会话；
- 不与“发送语音消息”共用同一个视觉状态，防止用户误判发送内容类型。

> **阶段 4 批次 B 落地（2026-08-16）：** 语音输入整体已实现（Mock 驱动，标「已开发、未联调」）——`CyChatInput` 增三入口：**🎤 普通录音**（click 开始/停止，录音中按钮高亮 + 时长）、**🔊 实时会话**（进入后输入区替换为 `CyRealtimeBar` 实时状态条，聆听状态 + 字幕 + 轮次数 + 停止，进行中发送按钮禁用）、**⌨️ 转写**（pointerdown 开始 / pointerup 提交 / 上滑取消，`CyDictationHint` 字幕浮层）；录音停止后 `CyVoicePending` 待发送条（转写字幕 / 等待中「正在识别…」/ 45s 超时后「未识别，请重试」+ 试听/重录/删除/确认发送，**无字幕时确认发送禁用**；等待期试听/删除/重录可用，错误与字幕可并存）；TTS 播放经 `CyTtsPlayer`（隐藏 `<audio>`，宿主 CyChatView，`autoReadReply` 播放门）；**后端 STT 首次操作前一次性同意**（D-P16）；**会话切换守卫**（语音会话活跃 `mode≠idle` 时禁止切换/新建，提示先结束，D-P5）；语音设置子页 `CyVoicePane`（启用/实时/TTS 自动朗读/字幕开关 + 麦克风设备下拉 + 测试麦克风 + 转写 STT 下拉 + 插入位置）。**「保留录音」设置项不在本批**（音频不落盘，该设置随保存/附件功能后续引入）；「光标级插入」为后续（见 §2.6）。

## 4. 安全策略

### 4.1 沙盒目录

每条记录包括：

- 规范化路径与展示路径；
- 允许读、写或执行受控模板；
- 创建来源；
- 关联工具；
- 有效期；
- 最近使用时间；
- 撤销操作。

沙盒只定义可能允许的范围，不覆盖黑名单和逐次确认策略。

### 4.2 路径黑名单

支持：

- 精确目录；
- 目录树；
- 文件名模式；
- 客户端内置不可删除规则；
- 用户自定义规则。

路径在匹配前必须规范化并解析符号链接或连接点。内置规则至少覆盖密钥、凭据和浏览器敏感数据目录。

### 4.3 域名黑名单

支持规范域名和受控子域通配符。匹配前进行大小写、末尾点、Unicode/Punycode 和端口规范化。

域名黑名单作用于：

- Desktop 侧自定义模型 Provider Endpoint；
- Desktop 网络工具；
- 受控命令模板声明的网络目标；
- 可配置的外部打开行为；
- Local Worker 网络工具。

它不应误伤客户端连接所需的已配置后端；冲突时明确提示用户处理，而不是静默绕过黑名单。

> **阶段 6 批次 C 注记（2026-08-21）**：§4.1~§4.3（沙盒目录/路径黑名单/域名黑名单）的**管理 UI 明确不落地**——D6B-14 常量化：仅黑名单零预授权（`PATH_BLACKLIST_DEFAULTS` 内置常量，含 /tmp 与用户敏感面，realpath 后段边界匹配），无管理 UI、无沙盒目录、无用户自定义规则面；黑名单优先与决策优先级（step 5 先拒、grant 匹配 step 8）见 doc 04 §7.4。§4.4 决策优先级生效形态 = tool-service 决策链。

### 4.4 策略优先级

```text
内置禁止规则
  > 用户路径/域名黑名单
  > 工具强制逐次确认
  > 有效范围授权
  > 沙盒默认权限
  > 每次询问
```

## 5. 权限审批历史

列表字段：

- 时间；
- 会话；
- 工具和 Runtime；
- 目标资源摘要；
- 风险等级；
- 用户决定；
- 使用的范围授权；
- 执行结果；
- 撤销入口；
- 脱敏错误码。

支持按时间、工具、Runtime 和决定筛选。历史记录不能显示完整文件、截图、录音、消息内容或密钥。

> **阶段 6 批次 C 落地（2026-08-21）**：审批历史由设置页「安全与权限」→ 审批历史分区承载（`CySecurityPane` ②）——数据源 `tool:history`（Main audit JSONL 回读：最近 `HISTORY_DAYS=7` 天、`tool:`/`grant:` 前缀过滤、ts 倒序、`HISTORY_MAX=200` 合并上限）：每项 ts/toolId/toolName/status 徽标/permissionDecision/summary（脱敏）/errorCode；支持**按工具过滤（全部/read/write/capture）+ 按结果过滤（全部/允许/拒绝/执行成功/执行失败/已取消）+ 搜索框**（匹配 summary/toolId）；`allow_scoped` 条目「撤销此授权」**跳转撤销**（F-21）。「不能显示完整文件/截图/录音/消息/密钥」要求不变——全部只读、不渲染原始参数。

## 6. 已授权命令和目录

### 6.1 目录授权

- 显示规范化路径；
- 读/写/受控执行权限分开；
- 绑定工具和后端身份；
- 显示有效期和最近使用；
- 支持立即撤销；
- 目录变化或符号链接目标变化时重新校验。

### 6.2 命令授权

命令必须以本地模板展示：

```typescript
interface AuthorizedCommandTemplate {
  id: string;
  title: string;
  executableLabel: string;
  fixedArguments: string[];
  variableArgumentSummary?: string;
  workingDirectoryIds: string[];
  readOnly: boolean;
  expiresAt?: string;
}
```

设置页不提供“允许任意 Shell”。用户需要看到命令模板、可变参数范围、工作目录、网络限制、授权来源和撤销操作。

> **阶段 6 批次 C 落地（2026-08-21）**：§6.1 目录授权落地为设置页授权管理分区（活动 grants 卡片列表：工具/目录（展示摘要，全路径来自 `tool:grants`）/后端身份（serverUrl origin）/有效期 + 「撤销」按钮；已撤销/已过期灰显无按钮（revokeSource 标注）；空态「暂无长期授权。在工具权限确认时选择「允许指定目录」可添加。授权存储在本机，可随时撤销。」）；**§6.2 命令授权不落地**——`desktop.command.run` 全阶段不注册，命令模板区为**空态**（**F-08 关闭**：「未启用受控命令执行。桌面工具仅包括文件选择/读取/写入与屏幕捕获，不支持任意命令执行。」，无列表无注册入口）。

## 7. Live2D 与外观

### 8.2 开发者模式

开启后可展示：

- Store 状态摘要；

应用自身提供的协议事件、Store 摘要、日志和诊断导出始终禁止包含：

- Token 和模型密钥；
- 完整 Inner Voice 或 Public Reply；
- 原始录音和完整转写；
- 完整文件或截图；
- 未脱敏敏感路径；
- 工具原始敏感参数。

生产构建默认关闭开发者模式。若允许开启，应二次确认并清晰显示当前状态。

Renderer DevTools 是更高风险能力：它天然可以检查当前已渲染 DOM、Renderer 内存和用户正在填写的临时表单，因此不能承诺 DevTools 看不到当前消息或刚输入但尚未提交的密钥。开启前必须明确告知该边界；已保存凭据仍不得通过 API 读回，远程调试端口始终关闭，关闭开发者模式或重启后恢复默认禁用状态。

## 9. 保存和错误处理

- 设置按分类保存，不因某一项失败回滚无关分类；
- 所有输入有 Schema、范围和格式校验；
- 服务测试和激活是两个独立操作；
- 保存凭据后立即清空明文表单；
- 安全策略修改记录审批来源；
- Live2D、字体和颜色支持即时预览，取消时恢复；
- 迁移失败保留旧设置；
- 设置依赖后端时显示“未同步”“同步中”“已同步”或错误。

## 10. 验收标准

- [ ] LLM、STT、TTS Profile 可以查看、测试和切换；输入法转写可独立选择兼容 STT Profile；
- [ ] 三种类型的自定义 LLM/STT/TTS Profile 都可以新增、编辑、复制和删除；
- [ ] 自定义模型保存前经过类型化能力测试，保存后可以立即切换；
- [ ] 密钥只显示配置状态，不回显明文；
- [ ] 自定义 Endpoint 的 HTTPS、本机 Provider、重定向、私网/元数据地址和 Header 规则可解释且不可绕过；
- [ ] 普通录音输入和实时语音会话可以独立启用；
- [ ] 普通录音停止后只生成待发送语音输入，直接语音字幕不会写入文字草稿；
- [ ] 按住说话转文字可以独立选择 STT Profile，只把最终文字写入草稿；
- [ ] 后端转写明确提示音频上传，本机/Local Worker 明确展示本地模型状态；
- [ ] 沙盒目录、路径黑名单和域名黑名单可管理；
- [ ] 黑名单优先于历史授权；
- [ ] 审批历史可查看且内容脱敏；
- [ ] 已授权命令和目录可查看及撤销；
- [ ] 命令授权不允许任意 Shell；
- [ ] Live2D 模型可以安全切换和失败回退；
- [ ] 字体和强调色可以即时预览及恢复；
- [ ] 前端日志目录可以打开和清理；
- [ ] 开发者模式默认关闭；应用诊断始终脱敏，DevTools 的当前页面可见性风险有二次确认说明且无远程调试。
